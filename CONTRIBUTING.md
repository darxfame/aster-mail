# Участие в Aster Mail

Aster Mail — независимый клиент Exchange OWA на Electron. Обсуждения и описания
изменений можно писать на русском или английском.

## Локальная разработка

Нужны Git, Node.js 22+ и npm:

```sh
git clone https://github.com/darxfame/aster-mail.git
cd aster-mail
npm ci
npm start
```

`npm run preview` открывает браузерное демо без авторизации в Exchange.
Структура проекта и соглашения по коду описаны в [AGENTS.md](AGENTS.md).

## Проверки и pull request

Перед PR выполните `npm run check` и `npm test`. Тесты используют встроенный
Node.js runner, вымышленные данные и подменный транспорт. Не проверяйте отправку
писем и приглашений автоматическими тестами на реальном ящике.

Опишите проблему, итоговое поведение и способ проверки. Для интерфейса приложите
скриншоты с демоданными; для протокола — тест запроса и обработки ошибок. Укажите
платформу и версию Exchange, если они влияют на результат.

Используйте короткие заголовки коммитов в повелительной форме, например
`Handle expired OWA sessions`. Сохраняйте MIT-атрибуцию и отдельную CC0-лицензию
звуков. Не добавляйте проприетарные модули Mustang.

Пароли, токены, cookies, корпоративные письма и журналы авторизации не должны
попадать в issues, PR, скриншоты или исходники. Об уязвимостях см. [SECURITY.md](SECURITY.md).
