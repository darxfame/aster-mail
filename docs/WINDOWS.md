# Сборка для Windows

Исходники рассчитаны на Electron, но Windows-интерфейс и интеграции пока не прошли
проверку на настоящей Windows. Успешная сборка установщика не заменяет эту проверку.

## Быстрый путь: GitHub Actions

Откройте **Actions → Windows installer → Run workflow**. Задача на Windows
установит зависимости, выполнит проверки и соберёт NSIS-установщик x64.
Скачайте `aster-mail-windows-x64-unsigned` из Artifacts завершённого запуска.
Отдельно теги `v<версия>` запускают workflow **Publish installers**: он
собирает macOS и Windows и публикует DMG и EXE в GitHub Releases после успеха
обоих заданий. Артефакт хранится 14 дней.

## Локальная сборка

На Windows нужны Git, Node.js 22+ и npm. Wine, Xcode и Mac не требуются.

```powershell
git clone https://github.com/darxfame/aster-mail.git
cd aster-mail
npm ci
npm run check
npm test
npm run dist:win -- --x64 --publish never
```

Установщик `.exe` появится в `release/`. Для Windows ARM64 можно отдельно
попробовать `npm run dist:win -- --arm64 --publish never`; эта архитектура ещё
не проверена. Зависимости установщика загружаются при сборке, поэтому нужен интернет.

## Что проверить перед релизом

- Установка, запуск, удаление и повторный запуск на чистой Windows 11.
- Заголовок окна, системные кнопки, масштаб 100–200%, светлая и тёмная темы.
- Значок в трее, виджет встреч и сохранение работы после закрытия окна.
- Баннеры и оба звука, в том числе при скрытом окне: Windows сейчас воспроизводит
  звук через интерфейс, этот путь требует отдельной проверки.
- Хранение и восстановление пароля через safeStorage/системную защиту Windows.
- Корпоративный VPN, доверенные сертификаты, формы OWA и NTLM.
- Почта, вложения, приглашения, подпись и занятость на тестовом аккаунте Exchange.

Параметры окна сейчас ориентированы на macOS; после проверки может потребоваться
адаптация заголовка для Windows. Текстовый отсчёт в системной строке меню есть
только на macOS; Windows использует значок в трее и раскрывающийся виджет.

## Подпись для распространения

Тестовую сборку можно собрать без сертификата. Для публичного распространения
понадобится настроить подпись Windows (сертификат или поддерживаемый сервис
подписи), хранить ключи только в GitHub Secrets и проверить поведение SmartScreen.
Подпись сама по себе не гарантирует отсутствие предупреждений репутации.

Источники: [сборка на разных платформах](https://www.electron.build/v26/docs/features/multi-platform-build/),
[подпись Windows](https://www.electron.build/docs/features/code-signing/code-signing-win/).
