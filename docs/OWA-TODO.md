# To do для последовательных релизов OWA

Целевая среда — HTTPS OWA без обязательного EWS. Будущие номера задают порядок.
Каждый завершённый этап имеет бизнес-ценность, версию, неизменяемый тег и два установщика.

## Исследования без обещания релизной функции

- [ ] Изменения за пределами первой страницы: OWA incremental/notifications или обход страниц.
- [ ] Потоковый транспорт только под подтверждённый контракт с безопасным sleep/VPN/logout.
- [ ] Офлайн-база только после изменения текущего запрета сохранять payload.
- [ ] Регулярные рассылки и Microsoft 365 Graph не входят в перенос данного сервера.

Для каждого этапа фиксировать проверенные версии сервера отдельно от mock-тестов.
Отправки/приглашения испытываются только на согласованном тестовом ящике.
