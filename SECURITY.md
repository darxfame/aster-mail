# Безопасность

Проект находится на ранней стадии. Исправления безопасности выпускаются для
последней версии; перед использованием проверьте её на тестовом аккаунте Exchange.

## Сообщить об уязвимости

Используйте **Security → Report a vulnerability** в GitHub, если доступна приватная
форма. Если её нет, создайте issue с просьбой предоставить приватный канал связи,
без описания эксплуатации и конфиденциальных данных.

Не публикуйте пароли, токены, cookies, письма, корпоративные адреса серверов или
сырые ответы Exchange. Для воспроизведения используйте вымышленные данные.

## Границы защиты

Приложение подключается к вашему Exchange напрямую по HTTPS, проверяет TLS и
ограничивает авторизацию тем же сервером. Пароль сохраняется только по выбору
пользователя с шифрованием Electron safeStorage. Интерфейс изолирован от Node.js;
HTML писем очищается и отображается в sandbox-iframe. Не отключайте эти защиты
для обхода проблем подключения.
