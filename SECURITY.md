# Безопасность

Проект находится на ранней стадии. Исправления безопасности выпускаются для
последней версии; перед использованием проверьте её на тестовом аккаунте Exchange.

## Сообщить об уязвимости

Используйте **Security → Report a vulnerability** в GitHub, если доступна приватная
форма. Если её нет, создайте issue с просьбой предоставить приватный канал связи,
без описания эксплуатации и конфиденциальных данных.

Не публикуйте пароли, токены, cookies, письма, корпоративные адреса серверов или
сырые ответы Exchange. Для воспроизведения используйте вымышленные данные.

## Границы защиты

Приложение подключается к вашему Exchange напрямую по HTTPS, проверяет TLS и
ограничивает авторизацию тем же сервером. Пароль сохраняется только по выбору
пользователя с шифрованием Electron safeStorage. Интерфейс изолирован от Node.js;
HTML писем очищается и отображается в sandbox-iframe. Не отключайте эти защиты
для обхода проблем подключения.

HTTP-подключения запрещены. Автоматическая загрузка картинок ограничена точным
HTTPS-origin OWA, включая порт и перенаправления, и использует отдельную сессию
без авторизации. Настройки и корпоративные локальные данные шифруются через
`safeStorage`, привязаны к аккаунту и удаляются при выходе. Старые данные
`localStorage` удаляются при запуске. Системные уведомления скрывают содержимое
по умолчанию; предпросмотр включается явно в настройках.
Выход и смена аккаунта отменяют незавершённые запросы. Уже принятую сервером
операцию отменить таким образом нельзя: при неопределённом результате
проверяйте OWA перед повтором.

Сохранение и открытие вложений в Windows требуют проверенной отметки
`Zone.Identifier` с `ZoneId=3` до записи содержимого. Неподдерживаемые файловые
системы отклоняются. Автоматические временные копии ограничены по числу, объёму
и возрасту; ошибки очистки должны быть видны пользователю.
Выход блокирует восстановление сохранённого аккаунта до попытки перечисления
и удаления локальных файлов. Полная недоступность файловой системы требует
явного сообщения о невозможности гарантировать удаление и запрет автовхода.
Растровый предпросмотр ограничивает размеры до декодирования и учитывает
распакованный объём. Анимации не допускаются в автоматический предпросмотр.
